PDBe Download Service

Use this page to download coordinate files and experimental data files, FASTA sequence files, and ligand data files for one or many PDB entries or small molecules.

Enter PDB or small molecule IDs and click 'Download' to save a compressed folder containing your files onto your local disk.

Each download includes a list of IDs successfully downloaded named contains.txt

Another file called missing.txt is present if any   Some common reasons for missing IDs are: - Obsolete IDs - Unreleased PDB IDs - The user requested NMR data for non-NMR IDs - Experimental data for the requested IDs were not deposited
